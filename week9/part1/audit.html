Audit procedure

  1. Open the published page in Chrome. Run Lighthouse in Mobile mode and save the HTML report before editing.
  2. Check image alternatives, visible labels, headings, landmarks, contrast and native buttons.
  3. Press Tab from the start; activate the skip link with Enter and continue through all controls.
  4. Fix the findings, rerun Lighthouse under the same settings and save the after report.
