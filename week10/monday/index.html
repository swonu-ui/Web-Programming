Week 10 Monday · Git

Run commands in your own local checkout of swonu-ui/Web-Programming. Review each diff before committing.

E1 · First repository and commit

For a separate practice folder, initialize Git, create an HTML file and inspect the first commit:

mkdir git-practice
cd git-practice
git init -b main
# Create index.html in your editor.
git add index.html
git commit -m "Add first HTML page"
git log --oneline

The existing Web-Programming repository is already initialized; do not reinitialize it for this exercise. Open the included HTML example.

E2 · Branch and merge

git switch -c feature/pastel-style
# Create style.css and link it from index.html.
git add index.html style.css
git commit -m "Style practice page with pastel colors"
git switch main
git merge feature/pastel-style
git log --oneline --graph --all

Capture the actual branch history. A file copy does not create a branch or merge.

E3 · Push to GitHub

In the existing Web-Programming checkout, merge the package files into the repository root. Then:

git status
git diff
git add index.html coursework-assets week9 week10 404.html
git commit -m "Add Week 9 performance and Week 10 coursework"
git push origin main

For the separate practice folder, create your own empty GitHub repository and add its actual remote before pushing. Never push the practice history over this course repository.

Evidence to save

  • First commit and git log output.
  • Branch/merge history.
  • Successful push output and the matching GitHub commit URL.
